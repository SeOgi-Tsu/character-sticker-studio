# H3 动态表情工作区

在同一角色项目中准备独立首帧和视频提示词，再到 H3 官方平台生成视频、裁切为 GIF。工作区不直接生成视频，也不内置 GIF 转码。

## 开始制作

1. 从侧栏进入「动态表情」，选择已确认造型的单人角色母版。动态母版与静态表情母版分别保存。
2. 选择角色类型、画风和场景质感。支持人形、吉祥物、动物、机械角色，以及软萌 Q 版、扁平梗图、毛绒小偶、精致动漫画风。
3. 从 22 条内置小剧场中选择一条，查看动机、触发、反差收尾与分段时间。
4. 打开「首帧生图」，复制提示词并搭配母版在图片平台生成该剧情的起势图，然后上传绑定。模板不附带私人角色图片。
5. 默认使用 I2VA：将本条场景首帧作为 Picture 1 上传，复制完整 H3 提示词。Ref2VA 则使用角色母版作为 Picture 1。
6. 勾选要生成的配方，点击「打包图片与提示词」。每条一个文件夹，包含 PNG、视频提示词 TXT 与首帧生图提示词。
7. 在视频平台生成后，根据实际动作节奏裁切并转换 GIF。界面的 4 / 6 / 8 秒和 1:1 是创作目标，最终以平台可用选项为准。

「首帧总览」可逐条核对构图、起势、道具和配图状态。已有工作区会提示补充缺少的模板，保留原有图片和编辑内容；旧版轻动作可在归档中查看。

## 一图一剧情

每条有效 I2VA 剧情使用自己的首帧，取消打包勾选不会释放占用。角色母版与 Ref2VA 身份参考可以共享。这是工作区的制作规则，不是模型技术限制。

系统按解码后的像素与尺寸检查重复：改文件名、重新压缩或重复上传同一张图仍会提示冲突。裁切或改像素后的相似图片需要人工判断，文件指纹不能判断画面语义。

旧工作区的重复草稿可以保存并逐张修复，但涉及冲突的导出会被阻止。未选中的归档卡不占用当前首帧；主动打包归档卡时仍检查所选图片。

角色、母版、画风、场景或起势改变后，旧首帧会标为需要更新。修改时长保留首帧，但手动编辑的旧视频提示词会过期；页面可下载上次编辑稿，避免丢失。

## 复用与编辑

- 名称、接话文案、场景、起势、分段动作和声音均可编辑。
- 收藏单个模板后，其他角色可从通用模板库添加；也可通过 JSON 导入导出分享模板。
- 通用模板只携带剧情和构图，不携带角色图片、项目编号或专属改写稿。换角色后重新配首帧。
- 手、爪、短肢和机械夹爪会按角色类型替换，仍需人工核对具体角色能否完成接触动作。
- 场景和动作描述用英文；中文名称与后期文案不会自动写进视频画面。

工作区自动保存，离开页面或切换项目会等待保存。服务端通过修订号拒绝覆盖其他页面的新修改；遇到冲突时可先「备份草稿」，该 JSON 用于人工恢复，区别于可直接导入的通用模板 JSON。

## 提示词格式与可选改写

本地提示词按 MiniMax H3 的 [官方提示词规范](https://github.com/MiniMax-AI/MiniMax-H3)组织：

- I2VA 使用首帧引用指令及 `integrated_multimodal_description`、`overall_soundscape`、`non_diegetic_music`。
- Ref2VA 使用六个规定字段，保持 Subject / Picture 引用和单镜头节拍一致。
- 页面标明「官方 Skill 格式 · 本地草稿」，这表示遵循格式，并非远程调用官方 Skill 或视频生成服务。

可选文字接口使用 OpenAI 兼容 `/chat/completions`，单独保存地址、模型和密钥。仅在点击改写时发送角色文字与当前草稿，不发送图片；可能产生文字模型费用。不配置也可以直接复制模板，或复制改写任务给其他 AI。

## 参考与质量检查

「参考研究」目前收录 28 个样本、10 个角色系列，包含来源链接、实际观察范围、聊天用途、创意改编、首帧条件与指标局限。静态漫画、截图相位和完整动画不是同一种证据；GIPHY Views、视频播放及商店心愿数也不等于 QQ 转发量。

参考索引随 ZIP 导出，不打包第三方原始媒体。角色表演原则见 [角色互动小剧场](CHARACTER_THEATRE.md)。

配方和首帧就绪不代表已经验证生成动效。检查成片时重点看角色辨识度、手与道具接触、实际位移、表情可读性，以及收尾是否保住笑点。

## 数据与实现

视频工作区、收藏模板、备份和可选文字接口配置分别保存在私有本机数据中；静态表情任务与素材保持兼容。新工作区默认没有生成图片，不会自动提交付费生成任务。

- `src/shared/video.ts`：类型、H3 提示词、首帧绑定和模板导出。
- `src/shared/theatre.ts` 及各剧场模块：22 条动作模板；`theatre.edition: 2` 为数据结构版本。
- `server/video.ts`：工作区保存、冲突检查、模板迁移、可选改写与 ZIP 导出。
- `src/shared/reaction-research.ts`：有来源与边界的参考索引。

接口详见 [API 契约](API_CONTRACT.md)。可使用深链接 `/?view=video&project=项目ID`；项目 ID 可省略。
