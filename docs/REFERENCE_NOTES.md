# 反应库设计与来源

内置反应是按聊天场景编选的原创动作配方，不是 QQ 使用量或全网传播量排行榜。来源清单与查阅日期集中维护在 [catalog.ts](../src/shared/catalog.ts) 的 `sources` 中，界面的「灵感与选款依据」读取同一份资料。

## 编选原则

- 先确定接收者能如何接话：回应、感谢、邀请、安慰、吐槽或轻轻逗人。
- 用一个清楚的动作或可见反差表达情绪；缩成聊天预览后，眼睛、嘴和关键接触仍能看懂。
- 混合特写、半身、全身、动作、道具、迷你情境和边缘探头，避免整套只换同一种表情脸。
- 人格影响习惯动作和喜剧反差；身份、发型、饰件和服装遵循角色设定及参考图的优先级。
- 小剧场用一个瞬间和一个主道具讲清处境，文字可有可无。轻松俏皮的反应通过眼神、手势和小道具表达亲近。
- 推荐选集不会覆盖已经保存的单张方案；普通日常、夸张反应和安静陪伴都应保留选择空间。

## 参考与授权

公开社区资料用于理解镜头、姿态、字体布局和互动关系。官方贴图示例包括 [Sakura Miko Sticker Vol.2](https://store.line.me/stickershop/product/34848049/en)；其余社区图源及适用边界见代码中的来源清单。页面可访问、可见点赞或收藏都不能直接证明最高使用量。

仓库不包含第三方表情原图，也不把参考角色的服装、吉祥物或整套画作当成本项目素材。制作自己的角色时，需要自行确认输入图片和其他素材的使用授权。

随包的三款中文字体附有独立许可证与上游哈希，见 [字体说明](../public/fonts/README.md)。这些是本项目选用的字体，不代表已经识别出社区参考图的具体字体。
