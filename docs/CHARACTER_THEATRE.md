# 角色互动小剧场

让一段短视频承担一句群聊回应，同时呈现角色性格。每条包括动机、触发、明显动作和反差收尾；单纯眨眼、抱着道具扭动或重复小幅摆手不自动构成剧情。

## 22 条内置模板

| 方向 | 剧情 |
| --- | --- |
| 回击与挑衅 | 贴脸连环拳；凑脸挑衅后被轻戳；招手引人靠近再戳鼻尖 |
| 夸张情绪 | 嘴硬爆哭后偷看；笑到打滚后装乖；笑到拍桌再笑崩 |
| 偷吃与分享 | 偷吃逃跑藏不住；假投喂后把大块留给对方 |
| 日常反应 | 掀被子炸毛；捏脸反抗；无语关门又偷看；举奖牌讨夸 |
| 搞笑翻车 | 举键盘后舍不得砸；玩手机被抓后装睡；汽水喷脸后甩锅 |
| 躲事与疲惫 | 纸箱潜水后连箱逃跑；跑了又回来拿外卖；咖啡续命失败 |
| 性格互动 | 假装牵手却交包；递玫瑰时打喷嚏；推开摸头的手又拉回来 |
| 围观吃瓜 | 快速凑成满屏大脸，左右看后仍贴近等下文 |

这些是可换角色的创作模板，不是传播效果排行榜，也不保证视频模型按所有细节执行。

## 表演原则

- 起势简短，爆发有明确加速、接触和回弹，收尾给观众看清反差的时间。
- 身体动作由重心和关节驱动。奔跑有落脚和位移；拍桌有掌心接触；打滚有侧倒、撑地与起身。
- 面部可以短暂漫画挤压、拉伸或夸张口型，但要回到可辨认的脸与造型。不能用持续变形或整张立绘漂动代替动作。
- 道具保持归属和状态：先接稳再放手、先放杯再栽枕头、咬过的食物保留咬痕。
- 观众参与必须说明哪一只手在何时接触什么。没有明确指定时不增加画外人。
- 镜头服务动作，不代替动作。贴脸查看靠身体前倾完成，背景直到被脸遮住前保持静止。
- 默片也应成立。音效辅助节奏，字幕不能替没有演出来的笑点作解释。
- 先保住剧情收尾，再按实际成片裁 GIF；不强制每条回到起势或承诺无缝循环。

## 首帧与场景

每条剧情独立设计景别、重心、手势和动作路径。身份母版可复用，场景首帧不共用。

摄影背景优先普通卧室、客厅、电脑桌、门口和阳台。遥控器、拖鞋、充电线等少量细节建立生活感；物件应参与事件或解释处境，不能占据动作路线。

出图后再校对描述：手若已经碰到道具，就不能再写成首次入场；门板挡着身体时不能强求露脚；高举动作要留头顶空间，贴脸动作要从足够远的起势开始。

## 时间与格式

默认 6 秒、1:1、I2VA，页面也可选 4 或 8 秒。每条以四段非均分节拍组织；数据结构支持 3–5 段严格递增的时间比例。

H3 官方格式约束字段、引用与镜头表示，不要求角色原地不动。功能使用和参考案例见 [动态表情工作区](VIDEO_WORKSHOP.md)。
