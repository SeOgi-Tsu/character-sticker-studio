# ComfyUI 接入契约（扩展设计，尚未实现）

目标是复用现有角色、反应卡、任务状态与导出流程，替换图片生成步骤。不是仅填地址就能运行任何 ComfyUI 工作流。

所需输入：

1. 从 ComfyUI 导出的 API 格式工作流 JSON。
2. 已安装的模型、LoRA 与自定义节点清单；配套版本与哈希。
3. 角色参考图输入节点、prompt 文本节点、seed、宽/高节点映射。
4. 最终输出节点 ID；确认输出是角色一致的图片而非预览中间结果。

建议服务端步骤：验证映射 → `/upload/image` 上传母版 → 替换已声明的节点值 → `/prompt` 提交 → 保存远程 prompt_id → `/history/:prompt_id` 恢复查询 → `/view` 下载结果。

敏感地址由部署者配置。取消需要区分删除排队任务与中止正在执行的工作流；不把取消本地轮询描述成已经停止 GPU 运行。远程 ID 已知时重启后查询原任务，远程 ID 不明时避免自动再次提交。

验收：同一母版的至少三种不同情绪、单张失败不影响其他张、任务重启恢复、错误的参考节点立即报错、工作流和模型缺失明确提示。通过后才把 ComfyUI 作为可用供应商展示。
