# 使用指南

绒绒工坊把角色参考图、Q 版母版和表情配方放在同一个项目里。先选定角色，再决定每张表情的动作与文字，最后生成并导出静态 PNG。

安装与启动见 [README](../README.md)，服务器配置与数据迁移见 [部署说明](DEPLOYMENT.md)。需要云端出图时，先阅读 [图片服务配置](PROVIDERS.md)；未配置可用的 API Key 和图片服务，工坊不会生成图片。

## 1. 选择起点

首次打开时，使用指南提供两条路线。填写名字和可选简介后，会创建一个独立项目，不会继承当前角色的图片或设定，也不会自动提交绘图请求。可以跳过，之后从侧栏「使用指南」重新打开。

### 我有角色图

1. 上传立绘、三视图或角色参考图。界面支持 PNG、JPG、WebP，单次上传最多 15 MB。
2. 在「角色设定」补充必须保留的发型、瞳色、饰件等特征。无需把整张图逐项重新描述。
3. 确认当前选用的参考图，点击「下一步：制作 Q 版母版」。

「沿用原图服装」是默认选项：参考图负责服装结构，服饰文字用于补充细节。如果确实要换衣服，选择「按文字换装」，再填写新服装。生成模型仍可能画错，请在选用候选图前检查。

### 从零描述角色

1. 填写名字、简要设定，以及希望保留的外貌、服饰和性格。
2. 配置图片服务，点击「云端生成角色图」。也可以使用下面的 Niji 提示词流程。
3. 放大查看生成的候选，点击「使用这张」作为角色参考图，再制作 Q 版母版。

### 使用 Niji 7 角色工坊

这里提供提示词编辑与图片导入，不会自动调用 Niji：

1. 先在「角色设定」填写角色信息，再打开「Niji 7 工坊」。
2. 选择「单人立绘」「角色三视图」或「三视图 + 大头细节」，按需调整风格化、Raw 和风格参考。
3. 复制提示词，到官方平台手动生成并下载图片。
4. 回到工坊导入结果，作为角色参考图使用。

修改布局或参数会重新生成模板，建议先定好参数，再编辑提示词正文。

## 2. 选角色图与 Q 版母版

角色参考图负责说明“这个角色是谁、穿什么”；Q 版母版用于统一脸型、比例、线条和画风。母版不要求后续表情重复它的姿势。

在「Q 版母版」选择一种画风，然后生成或上传已有 Q 版图。两类图片都有候选列表，最新记录在前，可预览、查看状态与时间，再点击「使用这张」。选定母版后，点击「下一步：制作表情」。

不满意时可以「再生成一张角色图」或「再生成一张母版」。旧图继续保留；同一项目的同类任务正在排队或生成时，按钮会暂时禁用，避免重复提交。任务状态也可在「生成记录」查看。

更换角色参考图或画风时，旧母版会取消当前选用，需要重新选择合适的母版；图片和记录不会删除。再次选择同一参考图，或只改普通描述、文案与道具设定，不会因此取消母版。

## 3. 挑选并定制表情

内置 **76 个可选反应配方**，并非预先生成好的图片，也不是使用量排行榜。可以从「可爱犯规 12」「百变可爱 12」「嘴硬小剧场 12」「角色小剧场 12」等选集开始，再逐张增减；「俏皮暧昧 6」也是可选选集，不会自动加入默认方案。

点开一张卡片后，可以修改：

- **镜头构图**：特写、半身、全身、完整动作、道具、迷你情境或探头。
- **互动与张力**：自在反应、扑向你、递给你、摸摸贴贴等关系，以及克制到夸张的表演程度。
- **动作与感受**：写一个清楚的主动作，再说明希望对方看完想回应什么。
- **文字**：单张决定是否加字，以及文字怎样出现。

没有合适的反应时，点击「自定义」，填写名称、动作和可选文案。选择选集会更换当前勾选范围，不会覆盖已经保存的单张文字、动作或小剧场设置。

### 让笑点符合角色

「角色设定」中的「表情人格简要」用于描述角色为什么这样反应：想显得镇定、喜欢逞强、被夸时躲开视线，或嘴硬但偷偷照顾人。预设会把明文简介填入编辑框，仍可自由修改；它不改变年龄、外貌或服装。

「专属小道具与符号」可以写常用颜色、图案或小物件。它只用于当前动作需要的道具，不要求每张都加入同样的符号。

单张「一张图的小剧场」包含三个可选字段：发生了什么、露馅的小细节、关键道具。例如“说自己没偷吃，但嘴角留着饼干屑”。重点是一张图里的一个瞬间，不需要长台词，也不会自动扩成多格漫画。关闭开关会保留填写内容，但停止把这段情境加入后续生成。

人格、构图、动作、服装和小剧场的修改，都在**下一次生成**时生效；已有图片不会自动重画。

## 4. 每张决定怎样加字

| 文字模式 | 图片怎样生成 | 之后怎样修改 |
| --- | --- | --- |
| 无字 | 生成干净图片，不添加后期文字 | 已填文案仍保留，可切回后期排字 |
| 后期排字 | 先生成无字原图，再由工坊排字 | 可改文案、字样、配色、位置、大小、换行和倾斜，也可关闭 |
| 随图生成 | 文案与角色一起画进图片 | 字已成为像素的一部分，改字或去字需要生成新图 |

后期排字有经典粗描边、快乐软糖、随手碎碎念、毛笔炸毛、软萌对话泡和漫画重击六种字样。切换字样会应用对应配色、大小与倾斜预设，保留文案、模式与位置；仍可继续微调。保存前的即时排字是草稿预览，保存或打开大图后可查看准确成品。

「随图生成」的文字画法和视觉大小是给模型的方向，需要检查实际错字、缺字与布局。**选择「无字」或取消后期排字，不会擦除原图中已经画好的字。** 想得到新的无字版本，请选择「无字」，再点击「按当前方案再画一张」。工坊不会在原生带字图上再叠一份后期字幕。

短句通常更容易排好；也可以让无字动作、轻声旁白和醒目大字在一套中混搭。

## 5. 先试图，再批量生成

先检查「模型与连接」，再选一张表情试跑。确认角色、服装、构图、文字和背景后，再生成选中的一组。每张表情独立提交任务，费用与速度由服务商决定。

「按当前方案再画一张」使用现在的设定，创建新版本；「使用原任务配方重试」沿用原提示词和参考图。想应用刚修改的服装或文案，应选择前者。

「生成记录」保留本项目的角色图、母版和表情，可筛选已完成、进行中或需要关注的任务。若状态不明，先核对服务商记录；已有 RunningHub 任务号时，优先「继续查询原任务」。取消本地等待不代表平台已经停止生成或计费。

## 6. 下载、导出与恢复

单张 PNG、大图预览和 ZIP **默认使用原始分辨率**，保留每张图片本来的宽高，不统一缩成 512，也不把长方形补成正方形。后期文字在原尺寸画布上绘制。需要小图时，可主动选择 256、512 或 1024 的正方形缩放版本。

在「打包带走」下载整套 ZIP，会按每种表情取本项目的**最新成功版本**，并非只导出当前勾选项。包内包含原始 PNG、联系表与配方；勾选「附上排字成品」会另附按当前文字设置输出的 PNG。选择缩放尺寸时，也会另附缩放版本。原生文字在这些版本中都会保留。

项目配方可以单独导出为 JSON，再从「导入项目配方」创建项目。它保存角色文字、选款、动作、人格、小剧场和文字设置，**不包含 API Key、参考图文件或完整生成历史**。导入后需重新选择图片并配置服务。需要保留全部图片与历史时，按 [部署说明](DEPLOYMENT.md) 备份工作室数据目录。

真实透明图会保留透明通道；白底图片仍是白底，不会自动变成透明图。当前流程制作静态图片，不自动生成 GIF 或平台专用表情安装包。

## 常见问题

| 遇到的情况 | 建议操作 |
| --- | --- |
| 点击生成后要求配置模型 | 在「模型与连接」填写协议、地址、模型或工作流，以及对应 API Key；保存配置本身不会试画 |
| 无法生成母版或表情 | 先选定所需参考图，再确认服务确实支持图片输入；RunningHub 还需映射参考图节点 |
| 服务能文生图，却不能生成角色表情 | 文生图成功不代表支持参考图编辑，按 [图片服务配置](PROVIDERS.md) 核对图生图协议 |
| 换参考图后母版不见了 | 只是取消当前选用，到候选或生成记录中重新选择；旧文件仍保留 |
| 修改文案后，旧图里的字还在 | 这是原生文字，需要「按当前方案再画一张」；关闭后期排字只能移除可编辑字幕 |
| 修改服装或动作后图片没变 | 这些设置用于下一次生成；历史重试也不会套用当前新方案 |
| 图片生成超时或状态不明 | 先查看服务商任务记录；RunningHub 有任务号时继续查询原任务，避免重复提交 |
| 返回 401、403、429 或接口错误 | 按 [图片服务配置](PROVIDERS.md) 检查密钥、模型权限、配额、并发和协议 |
| 刷新后指南重新出现或项目选择没记住 | 检查浏览器是否禁止本地存储；项目数据在工作室服务端，不依赖指南的显示状态 |
