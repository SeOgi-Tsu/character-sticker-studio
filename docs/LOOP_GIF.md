# 循环 GIF

在「动态表情 → 循环 GIF」中，上传角色母版、选择情景，直接生成和下载 GIF；每款都能单独配场景图。原有「剧情小剧场」仍保留独立首帧与提示词导出。

## 使用

1. 上传单人 Q 版母版，或选择已有静态素材。不限全身：捏脸适合大头、打字适合半身、躺平适合卧姿。
2. 在本页「配置会员连接」保存 RunningHub Consumer-Membership Key。与静态图片服务分开保存，不覆盖原来的图片模型。
3. 先试一个，确认角色与动作，再生成所选动作。新项目默认 10 款情景：捏脸、门后偷窥、键盘破防、被窝躺平、理线、喇叭、递水、草莓、坐地大笑、放大镜。旧项目点「加入并选择情景套装」保留原配方并添加新版。
4. 「改动作 / 配图」可编辑完整 H3 提示词、种子和专用参考图。专用图优先于共用母版；换角色时同时替换这些图。单独配好图的动作不要求再上传共用母版。修改后用于新任务，已提交任务沿用原快照。
5. 结果自动循环播放，可切换聊天尺寸；默认下载 256px 聊天版（128 色优化、保留帧时长和循环次数），也可选原始 GIF。支持逐张下载或打包每个动作的最新成功版本。已有 GIF 也可导入，动画帧原样保留。

当前内置资源是[梦影Erislia发布的循环工作流](https://www.runninghub.ai/post/2116526206026842114)。Pika H3 Flex 是 LoRA，MiniMax H3 Loop 是循环模型补丁，二者共同工作，不是两种互斥引擎。该页面只接入此固定工作流；任意其他工作流仍需开发者核对节点映射。

情景提示词允许脸颊挤压、遮挡、手与道具互动，保持角色身份而不锁死表情。没有统一强制全身站立或身体晃动。输入端使用 KJ 等比补白到方形，保留原比例并满足 32 倍数。

## 输出与接缝

2026-11-01 实测发布版输出 **512×512、68帧、25fps、2.72秒、无限循环 GIF**。发布图时长控件为 3 秒，帧桶与解码会影响实际时长；以后工作流变化，以下载文件的帧信息为准。

GIF 在云端工作流直接编码，不需要先导出 MP4。本页保留原始 GIF 字节，不通过 PNG 静态图片处理。表情文字目前只作为动作卡建议，不自动烧录到动画；当前不提供 GIF 后期叠字、透明抠图或视频转码。

自动重复播放不代表首尾无缝。看三轮，检查最后一帧衔接第一帧时人物位置、脸、发饰、手和背景有没有跳变；首末帧应表现连续运动，不必完全相同。高幅度动作与复杂手势更容易变形，必要时调整提示词重新生成。

## 任务与恢复

复用工坊原有任务队列、请求编号去重、冻结配置和远程任务 ID 恢复机制。会员类型在上传前验证为 `NORMAL`，账号占用达到 3 时等待空位；本机总并发最多 3，并继续服从图片设置里的更低并发值。

返回任务 ID 后立即持久化。网络或 GIF 下载/解码出错时保留 ID，可「继续查询」，不会新建付费任务；没有 ID 的不明提交不能自动重试。停止等待只停止本机查询，不保证远程取消或停止计费。

真实素材验证通过现有 Ersilia Workbench 队列进行，使用同一发布图；工坊适配器的上传、会员检查、去重、恢复、GIF 保存和下载通过本机 HTTP 夹具验证。私人 Lumi 素材、云端任务记录、密钥及本机数据库不随仓库发布。
