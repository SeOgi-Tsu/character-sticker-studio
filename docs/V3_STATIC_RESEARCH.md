## 从观察到原创设计

“前景手势、大小差、角色关系、表情与处境反差”来自以上观察。“摸头后发顶压低、捏脸后嘴角偏移、扑抱时手先到镜头”是结合用户目标的原创演绎，不包装成已验证的流行统计。

对应新的八张 Margaret 配方：扑抱、被摸头、递大花、角落探入、嘴硬捏脸、小小领导、突然摊平、安静贴屏。保留浅金双马尾、红眼、黑蝴蝶结与金色心形饰件，不引入蓝发、鲸鱼尾或鲸鱼娘服饰。

执行原则：

1. 先明确接收者是谁、接触或递物发生在哪里。
2. 一个主要的透视或反差重点，避免手、脸、文字一起争最大面积。
3. 身体姿态与接触后的变化要参与表演，不能只换五官。
4. 强烈与安静款交错，保留旧款的温柔和辨识度。
5. 眼睛、嘴巴、手臂归属和接触点仍需出图后检查；提示词不能保证模型正确执行。

本轮新样图使用本项目的 `buildStickerPrompt`，由 Codex 内置 image_gen 实际生成并作为外部样图导入。用户的云端API或RunningHub是否重现同等效果仍需实际配置后验证。
