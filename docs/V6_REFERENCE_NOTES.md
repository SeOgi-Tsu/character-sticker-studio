# V6：一个处境，让可爱有自己的笑点

## 本轮参考优先级

用户本轮提供的两张鲸鱼截图是主要方向。此前 MFuns 文章经用户复查后不再作为本轮主要依据；不要把其中模型失败/幻觉/服务问题直接移植成 Margaret 的人物设定。

附图一的右侧：鲸鱼娘抱着一群软圆小鲸鱼，亲近的抱持动作与故作高位的短句形成反差。可借鉴的是“明明很在意，却装作自己在照顾/管理对方”的关系，不是复制鲸鱼种族或同样的人偶堆。

附图二：完整跪坐的小身体、面前空碗、进入画面的指责手势与很小声的辩解，让一个生活处境在单张里成立。观众能接上“我被说中了”“我还要嘴硬”等日常反应。这里的设计判断来自所见画面，不等于已经证实其转发量。左侧搜索鱼片示例仅有裁切画格，未用它确定多格格式。

另外实看了 [hololive 官方 Sakura Miko Sticker Vol.2](https://store.line.me/stickershop/product/34848049/en)（检查日期 2026-09-08；页面注明 hololive、© COVER、插画 sakukoro）。店铺预览里可见大头、较小全身、趴下休息、手势与吉祥物反应穿插，同一角色的颜色和饰件让差异化表演仍可辨认。此处只参考混合尺度、简短文字和一眼可读的动作节奏，不复制服装、吉祥物、画作或台词，也不把在售页面当作当下热度排名。

第三方图片仅在用户附件与网页中观察；没有打包、搬运到开源项目或用作生图参考。

## 最后的设计取舍

1. 主体仍是一张可直接发聊天的表情，优先单格、单个瞬间。在一个小处境里让观众看见嘴硬露馅，而不是要求读完剧情。
2. 每张给一个接话机会：否认、替你保管、逞强、等你、偷偷照顾、留位置。完整反应库继续保留之前的开心、陪伴和安静可爱。
3. 关键道具控制在一件或一小组同类物品；用身体姿态和道具关系制造反差，既有发型、瞳色、饰件与原服装负责识别角色。
4. 角色专属符号可来自已有配色与饰件，如 Margaret 的黑蝴蝶结、金色心形。只在合适的小道具上呼应，不把所有物件变成爱心，不自动给角色增加角、尾、种族特征或新衣装。
5. 小剧场可逐张关闭，处境和道具文字保留；文字模式仍独立可选。无字、后期字、原生字按用途穿插，原生字仍要检查错字。
6. 传播目标用“能认出角色、缩小能读懂、日常能接话、值得重复使用”评估。没有声称具备客观的传播量预测能力。

## 新增原创小处境

偷吃露馅、替你保管、罐盖僵局、假装路过、偏心打伞、留着你的位置。基础姿态与可选小剧场分开保存，便于换角色、关掉剧情或重新写自己的道具笑点。
